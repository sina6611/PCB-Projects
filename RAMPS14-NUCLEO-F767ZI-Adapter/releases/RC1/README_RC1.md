# RAMPS 1.4 ↔ NUCLEO-F767ZI Adapter RC1

Engineering release candidate.

- NUCLEO side: CN7/CN8/CN9/CN10 Zio/Arduino headers only.
- No Morpho connectors.
- RAMPS side: Mega-pattern mating headers.
- 5-axis TMC2209 STEP/DIR/ENABLE.
- Six endstops.
- Three thermistor inputs.
- RAMPS D10/D9/D8 power-control outputs.
- AHCT output level translation to 5 V.
- 3.3 V-safe input/ADC interface.

**Status:** electrical design candidate; fabrication is still on HOLD until first-article mechanical fit of the RAMPS header geometry and stacking height is verified.
